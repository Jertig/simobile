# SIMOBILE

SIMOBILE adalah aplikasi kasir sederhana berbasis Ionic Angular untuk membantu pengelolaan produk, keranjang belanja, dan transaksi.

## Instalasi

Clone repository dan masuk ke folder project:

```sh
git clone https://github.com/Jertig/simobile.git
cd simobile
```

Install dependency:

```sh
npm install
```

## Menjalankan

```sh
ionic serve
```

Aplikasi dapat dibuka di http://localhost:8100.

## Build

```sh
ionic build
```

## Fitur

- Dashboard
- Daftar produk
- Pencarian produk
- Detail produk
- Tambah dan edit produk
- Keranjang
- Checkout
- Riwayat transaksi
- Detail transaksi
- Tab navigation
- Drawer navigation
- Custom theme
- Dark mode
- Animasi

## Teknologi

- Ionic
- Angular
- TypeScript
